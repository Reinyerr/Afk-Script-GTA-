#GTA V Anti-AFK Script (AutoHotkey v2)
This AutoHotkey v2 script prevents Grand Theft Auto V from disconnecting players due to inactivity. It automatically reactivates the GTA window before the AFK timer expires, performs randomized clicks and movement inputs to simulate natural gameplay, and then restores focus to the previously active window. This allows users to stay connected while multitasking outside of the game.

✨ **Features**

✅ Prevents AFK kicks by simulating random in-game activity

✅ Allows the user to tab out and continue other tasks

✅ Restores focus to the original window after activity

✅ Simple hotkey controls for starting, stopping, and exiting

✅ Force-close option for GTA V if needed

🎮 **Hotkeys**

F1 – Start the script

F2 – Pause/stop the script

F3 – Exit the script completely

F4 – Force-close GTA V safely (Alt+F4 + Enter spam)

**📂 How to Use
**
1. Install AutoHotkey v2.
2. Download this script and save it as GTA_AntiAFK.ahk.
3. Double-click the script to run it.
4. Press F1 to start. The script will keep you active in GTA V while you are tabbed out.
5. Use F2, F3, or F4 as needed to manage the script or the game.
